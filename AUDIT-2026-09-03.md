# Schema-versus-handler audit, 2026-09-03

Every Revit command was audited by comparing what its MCP tool promises (name, description, zod schema) with what its C# command, handler and model actually do. One finder agent per command (claude-sonnet-4-6) reported findings with file:line evidence; every high/medium finding was then handed to an independent verifier (claude-opus-4-6) instructed to refute it. Only findings that survived are listed as confirmed.

| | count |
| --- | --- |
| commands audited | 86 |
| confirmed findings | 182 (75 high, 107 medium) |
| refuted by the verifier | 17 |
| low severity, not verified | 38 |
| fixes applied by the repair sweep | 184 |
| already fixed before the sweep ran | 0 |
| deferred (needs new Revit functionality; tool made honest instead) | 14 |

Kinds: `param-mismatch` = the tool sends or documents a parameter the handler never reads, or reads under another key; `silent-failure` = the handler reports success although nothing (or not everything) happened; `unit-mismatch` = feet where millimetres were promised, or raw values passed to Revit; `description-wrong` = a claim the handler does not back.
